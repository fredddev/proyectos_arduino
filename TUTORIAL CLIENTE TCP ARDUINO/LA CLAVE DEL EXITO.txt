AT+CIPSTATUS = *) DEVUELVE 2 SI ESTA CONECTADO A UNA RED PERO NO AL SERVIDOR (DEVUELVE 4 SI SE CERRO LA CONEXION CON EL SERVIODOR Y ESTA CONECTADO AL WIFI)
	       *) DEVUELVE 3 SI ESTA CONECTADO A UNA RED Y A UN SERVIDOR		
	       *) 5 SI NO ESTA CONECTADO A NINGUNA RED(SE RECONECTA SOLO)


AT+CIFSR = devuele el ip, mac

AT+CIPSTA="192.168.100.72" //establece el ip

AT+CWLAP = buscar redes

AT+CWQAP =  desconectarse de la red

AT+CWMODE?  = devuelve en que modo esta (2=como router o servidor,1=como host,3=mixto)
AT+CWMODE=3 = establece en que modo estara(en este caso seria como mixto)

AT+CWJAP="SSID_nuestra_conexión","contraseña"  = para conectarme a una red


AT+RST =  reinicia el modulo(no resetea)
